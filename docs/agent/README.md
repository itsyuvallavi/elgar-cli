# docs/agent

## Purpose

Agent instructions, roster, and historical handoffs for Elgar.

## Files

- `AGENTS.md` is the active agent instruction file.
- `AGENT_ROSTER.md` lists standing specialist roles.
- `GOOGLE_DRIVE_PLANNING_SOURCES.md` lists old planning sources.
- `history/` contains old handoffs and Linear sync notes.

## Rule

Use `AGENTS.md` plus the current docs in `docs/` for active work. Treat
`history/` as background only.
