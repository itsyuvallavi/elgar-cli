# Elgar File Map

## Root

- `AGENTS.md` contains repo instructions for agents.
- `README.md` introduces the project and common commands.
- `Cargo.toml` defines the Rust workspace.
- `Cargo.lock` pins Rust dependency versions.
- `elgar-provider.json` configures the local provider.
- `elgar-mcp.json` configures optional MCP servers.
- `.elgar/` stores local runtime logs.
- `target/` is generated by Cargo and can be deleted when disk space matters.

## Crates

`crates/elgar-core/`:

- reusable runtime engine
- provider connection logic
- sessions/events
- logs
- current harness path

Key provider/harness streaming files:

- `crates/elgar-core/src/provider/http/transport.rs` sends local HTTP requests
  and owns connection/request setup.
- `crates/elgar-core/src/provider/http/stream_transport.rs` reads streaming
  HTTP responses and can stop on protocol completion.
- `crates/elgar-core/src/provider/lm_studio/openai/chat_streaming.rs` sends
  normal OpenAI-compatible streaming chat requests.
- `crates/elgar-core/src/provider/lm_studio/openai/streaming.rs` assembles
  streamed reasoning/text/tool-call chunks.
- `crates/elgar-core/src/provider/lm_studio/openai/tool_streaming.rs` sends
  tool-enabled streaming requests.
- `crates/elgar-core/src/harness/harness_loop/provider/synthesis_stream.rs`
  logs streamed synthesis chunks.

Key harness loop control files:

- `crates/elgar-core/src/harness/harness_loop/control/entrypoint.rs` exposes
  public loop wrapper functions.
- `crates/elgar-core/src/harness/harness_loop/control/coordinator.rs` sequences
  one bounded primitive loop.
- `crates/elgar-core/src/harness/harness_loop/control/loop_setup.rs` builds
  loop-local registry, budget, memory, and initial messages.
- `crates/elgar-core/src/harness/harness_loop/control/model_text_round.rs`
  handles provider prose claim checks and text finish paths.

`crates/elgar-tui/`:

- interactive terminal UI
- input handling
- slash commands
- rendering

`crates/elgar-cli/`:

- binary startup
- runtime path/config lookup
- diagnostic CLI commands
- CLI smoke tests

## Docs

- `docs/PROJECT_PLAN.md` is the rebuild plan.
- `docs/ARCHITECTURE.md` explains the current system.
- `docs/LOCAL_CHECKS.md` explains verification.
- `docs/PROVIDER.md` explains LM Studio/provider config.
- `docs/LOGGING.md` explains local logs.
- `docs/MCP.md` explains MCP config, HTTP model access, transports, and safety rules.
- `docs/TUI.md` explains the terminal UI.
- `docs/TOOL_CAPABILITY_MODEL.md` explains the intended low-level capability
  model for future agent tools.
- `docs/HARNESS_REFACTOR_PLAN.md` records selective cleanup and the harness debt inventory.
- `docs/agent/` contains agent instructions.
- `docs/archive/` contains historical plans and stale generated maps.
- `docs/maps/` contains current visual sketches.

## Scripts

`bin/` contains current local helper scripts. Old dogfood/performance scripts
live in `bin/_archive/`.

## Generated Or Local-Only

- `target/` is generated Rust build output.
- `.elgar/` is local runtime data.
- `.DS_Store` should not be committed.
