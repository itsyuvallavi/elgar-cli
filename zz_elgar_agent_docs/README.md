# zz_elgar_agent_docs

## Purpose

Active agent instructions, roster, and planning-source guidance for Elgar v0.2 work.

## Important Files

- `AGENTS.md` is the active agent entry point.
- `AGENT_ROSTER.md` defines the stable implementation roles.
- `GOOGLE_DRIVE_PLANNING_SOURCES.md` points to canonical planning docs.

## Ownership

Update these files only when agent operating rules or planning-source rules change. Keep instructions short and enforceable.

## Checks

- Confirm links and referenced paths still exist.
- Include agent-doc changes in the implementation report.
