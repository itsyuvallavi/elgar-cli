# Elgar File Map

## Root

- `AGENTS.md` contains repo instructions for agents.
- `README.md` introduces the project and common commands.
- `Cargo.toml` defines the Rust workspace.
- `Cargo.lock` pins Rust dependency versions.
- `elgar-provider.json` configures the local provider.
- `.elgar/` stores local runtime logs.
- `target/` is generated by Cargo and can be deleted when disk space matters.

## Crates

`crates/elgar-core/`:

- reusable runtime engine
- provider connection logic
- sessions/events
- logs
- current raw chat path

`crates/elgar-tui/`:

- interactive terminal UI
- input handling
- slash commands
- rendering

`crates/elgar-cli/`:

- binary startup
- runtime path/config lookup
- diagnostic CLI commands
- CLI smoke tests

## Docs

- `docs/PROJECT_PLAN.md` is the rebuild plan.
- `docs/ARCHITECTURE.md` explains the current system.
- `docs/LOCAL_CHECKS.md` explains verification.
- `docs/PROVIDER.md` explains LM Studio/provider config.
- `docs/LOGGING.md` explains local logs.
- `docs/TUI.md` explains the terminal UI.
- `docs/agent/` contains agent instructions.
- `docs/archive/` contains historical plans.
- `docs/maps/` contains generated visual maps.

## Scripts

`bin/` contains current local helper scripts. Old dogfood/performance scripts
live in `bin/_archive/`.

## Generated Or Local-Only

- `target/` is generated Rust build output.
- `.elgar/` is local runtime data.
- `.DS_Store` should not be committed.
